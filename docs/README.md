## Граница публикации

В Git не публикуются рабочие планы, внутренние аудиты, sprint/rollout receipts,
локальный контекст, credentials, node snapshots и исторические технические
заметки. В рабочем checkout они находятся в ignored
`.local_project_docs/`: текущие задачи — `TODO.md`, выполненная работа —
`DONE.md`, прежние материалы — `archive/`.

`PROJECT.md` и `AGENTS.md` в корне остаются техническими entrypoint-файлами
репозитория; они не заменяют это пользовательское руководство.
