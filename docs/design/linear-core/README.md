# Sub Manager — Design 02 / Linear Core handoff

Этот архив — самостоятельное техническое задание и визуальный шаблон для переноса существующей админки Sub Manager в концепцию **02 Linear Core**.

## С чего начать

1. Прочитать `AGENT-BRIEF.md` — обязательные правила для AI-исполнителя.
2. Прочитать `docs/DESIGN_SYSTEM.md` — визуальная система и токены.
3. Свериться с `docs/SCREEN_REQUIREMENTS.md` — состав экранов и данных.
4. Использовать `linear-tokens.css` как источник CSS-переменных.
5. Изучить `reference-src/App.tsx` и `reference-src/index.css` как работающий референс. Целевой вариант в коде называется `.theme-linear` и имеет ID `02`.
6. Перед сдачей пройти `docs/MIGRATION_CHECKLIST.md`.

## Что внутри

- `AGENT-BRIEF.md` — промпт и ограничения для Claude Desktop.
- `linear-tokens.css` — базовые токены темы 02.
- `docs/DESIGN_SYSTEM.md` — подробная спецификация визуального языка.
- `docs/COMPONENT_RECIPES.md` — правила компонентов и состояний.
- `docs/SCREEN_REQUIREMENTS.md` — обязательные разделы админки.
- `docs/MIGRATION_CHECKLIST.md` — критерии готовности.
- `reference-src/` — текущий React/Vite-прототип целиком.

## Главный принцип

Это не маркетинговый SaaS-dashboard. Это плотная операторская инфраструктурная панель: много данных, короткие пути к действиям, предсказуемая геометрия и минимальное визуальное украшательство.

## Как это внедрено в Sub Manager

Linear Core подключён как второй дизайн рядом с классическим, а не вместо него. Переключатель «Старый дизайн | Новый дизайн» стоит в футере сайдбара под выбором языка, выбор хранится в `localStorage` (`msm.ui.design`), по умолчанию классический.

- Атрибут `data-design="classic|new"` на `<html>`.
- Токены и стили нового дизайна: `frontend/src/design/new/*.css`, все правила под `:root[data-design="new"]`.
- Палитра для inline-стилей: `frontend/src/contexts/ThemeContext.tsx`.
- Пункт `AGENT-BRIEF.md` «переделываешь существующую админку» здесь означает: меняется только новый дизайн, классический остаётся без изменений.
