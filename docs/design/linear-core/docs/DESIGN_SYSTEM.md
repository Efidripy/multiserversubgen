# Design System — 02 Linear Core

## 1. Характер

Сдержанный, быстрый, технический, монохромный. Интерфейс должен ощущаться как профессиональный инструмент управления инфраструктурой. Акцент создаётся иерархией, контрастом текста, тонкими границами и статусными цветами — не декором.

Ключевые слова: dense, precise, quiet, operational, predictable.

## 2. Цвет

Использовать переменные из `linear-tokens.css`.

- Фон приложения: почти чёрный `#0b0b0c`.
- Сайдбар: `#0e0e0f`.
- Карточка: `#111112`.
- Вторичный/активный фон: `#19191b`.
- Граница: `#27272a`; усиленная: `#3f3f46`.
- Основной текст: `#f4f4f5`.
- Вторичный текст: `#a1a1aa`; muted: `#71717a`.
- Основной акцент остаётся нейтральным `#e4e4e7`.
- Цвет допускается только для статуса: green success, amber warning, rose danger, cyan info.

Запрещено: большие цветные заливки, фиолетовые/оранжевые градиенты, glow вокруг обычных карточек.

## 3. Типографика

- UI: Inter.
- Технические данные, IP, UUID, версии, URL и показатели: monospace.
- Заголовок раздела в topbar: 9–11 px, 700, uppercase, letter-spacing 0.08em.
- Заголовок карточки: 10–12 px, 600.
- Основные значения: 14–18 px, 600–700.
- Label: 5–7 px, uppercase только для служебных меток.
- Таблицы: 6–8 px в масштабе прототипа; в реальном desktop UI ориентироваться на 12–13 px.

Не использовать больше трёх уровней размера внутри одной карточки.

## 4. Сетка и ритм

Базовый шаг — 4 px. Основные интервалы: 4, 8, 12, 16, 24.

- Между карточками: 8 px.
- Внутренний padding компактной карточки: 12 px.
- Внутренний padding большой панели: 14–16 px.
- Высота topbar: 49 px.
- Высота контролов: 28–34 px, одинаковая в одной строке.
- Радиусы: 3–7 px. Не использовать pill-форму для крупных контролов.
- Соседние аналитические карточки обязаны иметь одинаковую высоту.
- Заголовочные области соседних карточек обязаны занимать одинаковую высоту.

## 5. Карточки

Карточка — border 1 px + surface, без тени. Тень допустима только у dropdown/modal/drawer.

В карточке:
1. служебная метка;
2. название;
3. контент;
4. опциональный footer с действиями.

Не смешивать в одной панели несвязанные задачи.

## 6. Навигация

Основные пункты:

1. Панель управления
2. Inbound
3. Клиенты
4. Статистика
5. Мониторинг
6. Резервные копии
7. Подписки
8. Telegram

Expanded sidebar: версия сверху, стрелка справа, подписи пунктов, профиль и сервисные действия снизу.
Collapsed: 52 px, только иконки, снизу профиль/выход/главная.
Mobile: expanded drawer 218 px поверх контента; collapsed rail 52 px, основной контент получает отступ 52 px.

## 7. Topbar

Слева только иконка + название активного раздела. Никаких breadcrumbs и описаний. Справа: command search, notifications, profile.

## 8. Статусы

- online/active/success — green;
- checking/warning — amber;
- offline/error/delete — rose;
- нейтральный статус — gray;
- данные/ссылка — cyan только при необходимости.

Всегда сочетать цвет с текстом/иконкой, не кодировать смысл одним цветом.

## 9. Адаптивность

Desktop: плотные таблицы и многоколоночные панели.
Tablet: аналитика в одну колонку, таблицы имеют horizontal scroll.
Mobile: sidebar drawer/rail, метрики 2 колонки, формы 1 колонка, action bars прокручиваются горизонтально.
