Новый дизайн Sub Manager: три направления

Панель управления VPN-флотом: ноды 3x-ui, инбаунды, клиенты, трафик, подписки и Telegram-бот. Админ заходит сюда каждый день, с ноутбука и с телефона, и в первую очередь проверяет: живы ли ноды, сколько людей онлайн и не кончается ли трафик.

СейчасОдна тёмная тема: navy #0A0E1A, cyan #22D3EE, IBM Plex Sans, радиус 8px. Её не трогаем.
СтекReact 18, Vite, Tailwind v4, i18next (ru, en), lucide-react. Стили в App.css и около 190 inline-стилях из ThemeContext.
ПринципОдна разметка и одна логика, две «кожи». Новый дизайн подключается атрибутом data-design="new".

Светлая, точная, как схема метро. Каждая нода — своя «линия» со своим цветом, статус показан формой станции, а не цветом.

Типографика

Commissioner 800 для заголовков страниц и крупных чисел, плотный трекинг −0.03em. Golos Text 400/500/600 для всего остального: шрифт сделан под русский интерфейс госуслуг и хорошо держит мелкий кегль. Шкала 12.5 / 14 / 17 / 26 / 34. Цифры табличные.

Палитра и контраст

paperinkslatecobaltлинии

Холодная бумага вместо кремового фона. Кобальт только для действий. Цвета линий только для идентификации нод. Ink на paper 15.4:1, slate на белом 5.6:1.

Сетка и отступы

Навигация горизонтальной строкой вверху, контент на всю ширину, 12 колонок, шаг 4px, ритм 8 / 12 / 16 / 22 / 28. Таблицы во всю ширину, панели с радиусом 12px, кнопки и поля 8px, статусы-«пилюли» круглые.

Иерархия

  • Заголовок страницы и одна схема-«маршрут» трафика.
  • Три числа строкой, без плиток.
  • Таблица, главный рабочий объект.

Кнопки, формы, таблицы, навигация

  • Основная кнопка кобальтовая, вторичная белая с тонкой рамкой.
  • Поля на серой бумаге, при фокусе кольцо кобальта 2px.
  • Строки таблиц разделены тонкими линиями, без зебры.
  • Активная вкладка отмечена полосой снизу.

Анимация

Один заметный момент: линии трафика прорисовываются при открытии дашборда за 600 мс. Остальное короткое, 120–160 мс: подсветка строки, смещение полосы вкладки. При prefers-reduced-motion линии появляются сразу.

Адаптив

1440: всё как на макете. 768: вкладки прокручиваются вбок, числа в две строки. 375: внизу панель из 5 вкладок плюс «Ещё», таблицы превращаются в списки «станций», модальные окна открываются на весь экран.

B. Стойка

Тёмная, плотная, как приборная панель серверной стойки. Всё выровнено по модулю 44px (высота строки), статусы показаны индикаторами, работа с клавиатуры через Ctrl+K.

Палитра и контраст

Тёплый графит вместо холодного navy, чтобы не повторять старую тему. Янтарь как цвет активного выбора и основной кнопки. Зелёный и красный только у индикаторов. Bone на graphite 13.9:1.

Сетка и отступы

Модуль 44px: строка таблицы, шапка и фильтры ровно 1U, плашка метрики 2U. Узкая иконочная колонка 64px. Радиус 2px, глубина задаётся светлой линией 1px по верхней грани, как у металлической панели.

Иерархия

  • Метрики с индикаторами-шкалами.
  • Таблица во всю ширину, зебра по строкам.
  • Командная палитра (Ctrl+K) для переходов и действий.

Кнопки, формы, таблицы, навигация

  • Кнопки прямоугольные, утапливаются при нажатии.
  • Поля тёмные, при фокусе рамка янтарная.
  • Числа в таблицах моноширинные, выровнены вправо.
  • Навигация в виде иконок с подписью при наведении, активный пункт отмечен янтарной меткой.

Анимация

Быстро и механически, 80–120 мс, без пружин. Индикатор мигает один раз, когда меняется статус ноды. Шкалы плавно доезжают до нового значения при обновлении данных.

Адаптив

1440: две колонки панелей. 768: колонка иконок остаётся, метрики в ряд по 3. 375: колонка уходит в нижнюю панель, у таблиц первая колонка закреплена, остальные прокручиваются вбок. Цель: максимум данных на экране.

C. Атлас

Спокойная, просторная, удобная для телефона. Ноды сгруппированы по странам, крупные мягкие поверхности, нижние панели вместо модальных окон.

Как это встроится в проект

Изоляция двух дизайнов

  • На <html> ставится атрибут data-design="classic" или "new". Если значение не сохранено, используется classic.
  • App.css не меняется. Новые стили лежат в src/design/new/*.css, каждый селектор начинается с :root[data-design="new"], слой design-new подключается после components.
  • Токены нового дизайна хранятся в одном файле tokens.css: цвета, шрифты, отступы, радиусы, длительности.
  • Inline-цвета из ThemeContext.colors берутся по текущему дизайну. Для classic объект остаётся прежним байт в байт.

Переключатель

  • Компонент на базе существующего ChoiceChips, ставится в Sidebar сразу под выбором языка и в мобильном меню.
  • Срабатывает без перезагрузки: меняется атрибут на <html> и контекст.
  • Выбор хранится в localStorage (msm.ui.design). На бэкенде нет хранилища пользовательских настроек, проверено по backend/routers/auth.py.
  • Новые ключи design.* в ru.json и en.json. Язык при переключении не меняется.
  • Светлая или тёмная тема — отдельная настройка, этот переключатель её не затрагивает.

Защита старого дизайна

  • Перед правками снимаются эталонные скриншоты classic на 375, 768 и 1440 по всем вкладкам.
  • После каждого этапа выполняется попиксельное сравнение с эталоном.
  • Логика, API и маршруты общие. В разметку компонентов добавляются только классы-зацепки, старый CSS их не использует.

Распределение работы после выбора

Claude CodeАрхитектура, tokens.css, оболочка (сайдбар, топбар, раскладка), технические задания, приёмка, интеграция, git, визуальная проверка.
CodexВетка codex/design-switch: контекст дизайна, переключатель, i18n-ключи, цвета ThemeContext для нового дизайна, тесты vitest (по умолчанию classic, сохранение выбора, язык не меняется). Затем стили экранов дашборда и мониторинга.
Antigravity (agy)Ветка agy/design-components: стили таблиц, форм, модальных окон, кнопок, чипов в src/design/new/components.css. Затем проход по адаптивности и предложения по композиции.
ПересеченияКаждый агент работает в своём worktree со своими файлами. Общие файлы (tokens.css, Sidebar.tsx, main.tsx) меняет только Claude. Вливание по одной ветке, после каждой прогоняются тесты.

Что нужно от вас

Выберите A, B или C. Можно с правками: например, «A, но тёмная по умолчанию» или «C с плотными таблицами из B». До выбора реализацию не начинаю.
